# AI Resume Analyzer

An AI-inspired Resume Analyzer that evaluates resumes, detects skills, identifies career fields, and provides ATS-focused suggestions.

## 🚀 Features

- Resume PDF upload
- Resume score calculation
- ATS compatibility score
- Automatic skill detection
- Career field identification
- Missing skill recommendations
- Resume improvement suggestions
- Simple and responsive user interface

## 🧠 Career Fields Supported

- IT / Software
- Data / Analytics
- Finance / Accounting
- Marketing
- HR
- Sales / Business
- Design
- General / Professional

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- PyPDF
- Flask-CORS
